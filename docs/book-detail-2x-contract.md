# 2x 책 상세 촬영 좌표 계약

`1x 전체 썸네일`과 `2x 책 상세`는 서로 다른 자산과 좌표계로 취급한다.

1. 선생님이 책 영역 설정을 열면 기존 1x 썸네일 위에서 책 사각형을 바로 편집하지 않는다.
2. 현재 프로토타입의 2x 창은 센서 중앙으로 고정한다. 책이 이 중앙 2x 화면 안에 들어오도록 거치 위치를 맞춘다.
3. 학생폰은 선택한 12MP/50MP 모드를 먼저 적용하고 CameraX `setZoomRatio(2f)`로 실제 2x 보정 사진을 새로 촬영해 보낸다.
4. 선생님은 `2x 책 상세 기준 화면`이라고 표시된 이 사진 전체를 보고 책 영역을 이동·조절한다.
5. 줌 비율은 양쪽 앱에서 2.0으로 고정하고, 저장 메시지는 2x 사진 내부의 정규화된 책 사각형을 전달한다. 화면 회전 180도 변환은 전송 좌표와 분리한다.
6. 이후 상세 사진은 동일한 zoom/crop 좌표, 해상도 모드와 초점 지점을 사용한다. 썸네일은 계속 1x 전체 화면을 사용한다.
7. 2x 전환·초점·복귀 시간에는 자리/책 움직임 판정을 중단하고, 1배 복귀 뒤 비교 기준 프레임을 새로 잡는다.

수용 기준: 설정 화면과 실제 상세 JPEG에서 책 사각형의 네 변 오차가 각 축 2% 이하여야 하며, 세로·가로 및 180도 표시에서 동일해야 한다.
